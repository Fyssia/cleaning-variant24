Обработка персональных данных

Какие данные используются

Для оформления уборки нужны имя, телефон, электронная почта и адрес. Данные заказа доступны его заказчику, назначенной бригаде и сотрудникам, которые обрабатывают заказ.

Для чего нужны данные

Данные используются для связи по заказу, планирования уборки и исполнения договора. Регистрация требует согласия на обработку персональных данных.

Учебные данные

Этот проект предназначен для демонстрации. Учётные записи и адреса демонстрационной базы вымышлены.
