## Запуск на Linux

Python 3.12 или новее. Команды выполняются из каталога проекта:

```sh
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python manage.py migrate
python manage.py seed_demo
python manage.py runserver 127.0.0.1:8024
```

Открыть http://127.0.0.1:8024/. На Windows вместо `source` используется `.venv\Scripts\activate`. На NixOS можно использовать `nix-shell` из каталога проекта; альтернативный запуск через `.venv` проверен на NixOS с Python 3.14.

`.env.example` содержит образец настроек. Для учебного локального запуска создавать `.env` необязательно. `db.sqlite3`, `media/`, секреты и виртуальное окружение исключены из Git. Команда `seed_demo` создаёт вымышленные данные и фотографии; заполненную базу не перезаписывает.

## Структура

- `config/`: настройки, общие маршруты и обработчики 403/404.
- `catalog/`: услуги, поиск, фильтры и JSON для обновления каталога.
- `accounts/`: заказчики, адреса, регистрация, вход и проверка ролей.
- `orders/`: формы, расчёт цены, создание разовых заказов и серий.
- `crews/`: бригады, расписание, назначения, наряды и сводка.
- `reviews/`: отзывы, проверка фотографий и сохранение вложений.
- `templates/base.html`: общие шапка, навигация и подвал. Шаблоны разделены по приложениям.
- `templates/includes/`: поля форм, пагинация и навигация кабинета.
- `static/css/site.css`: UI-kit, Grid, Flexbox и адаптивность. Inline-стилей нет.
- `static/js/site.js`: меню, клиентская валидация, калькулятор и живой поиск.
- `static/fonts/`: локальные поднаборы Noto Sans в WOFF2 и лицензия.
- `static/images/`: компактные SVG-иллюстрации услуг с фиксированными размерами.
- `evidence/`: результаты проверок, HTML страниц, скриншоты и сравнение с макетами.
- `tools/`: воспроизводимые сценарии проверки и оптимизации ресурсов.

## Страницы и данные

Реализованы 23 страницы из макета и две дополнительные: поиск и описание обработки персональных данных. Для динамических адресов в `evidence/pages.json` указаны реальные объекты и демонстрационные аккаунты.

Карточки, тарифы, коэффициенты, отзывы, адреса, заказы, бригады и остатки материалов читаются из SQLite через ORM. Каталог и список заказов используют пагинацию по 20 записей. В шаблонах применяются циклы, условия, `date`, `floatformat` и `truncatechars`. Все внутренние ссылки строятся через именованные маршруты.

## Формы и JavaScript

Регистрация, адрес, заказ, отзыв и назначение бригады имеют серверную валидацию и CSRF. После успешного сохранения выполняется перенаправление и показывается сообщение. При ошибке значения остаются в форме. Вход, смена пароля и выход используют Django Auth; выход принимает только POST.

Без перезагрузки работают:

1. Калькулятор: `GET /api/estimate/` возвращает цену, длительность и позиции. Тарифы всегда берутся на сервере; перед сохранением цена пересчитывается.
2. Живой поиск, фильтры, сортировка и пагинация: `GET /api/services/` возвращает JSON с HTML-фрагментом. Вывод экранируется Django.
3. Меню на телефоне: кнопка сообщает состояние, Escape закрывает меню и возвращает фокус.

Клиент проверяет обязательность, почту, телефон, длину текста и размер вложений. Сервер независимо проверяет те же ограничения, принадлежность адреса и заказа, статус уборки, тип фото и пересечения расписания. Назначение серии выполняется атомарно.

## Проверка

```sh
python manage.py check
python manage.py makemigrations --check --dry-run
python manage.py test catalog
python tools/export_pages.py
npm ci --prefix tools
node tools/browser_check.mjs
python tools/validate.py
node tools/lighthouse_check.mjs home services order_new
```

Для другой локальной точки входа задайте `SITE_URL`. Сценарии браузера запускают отдельный headless Chromium, не используют рабочий стол и реальный курсор. На NixOS используется системный Chromium; для других систем установите Chromium через Playwright, а для Lighthouse при необходимости задайте `CHROME_PATH`.

`evidence/browser-checks.json` содержит проверки ширин 360, 375, 768, 1024 и 1440 px. Полные скриншоты находятся в `evidence/screenshots/375/` и `evidence/screenshots/1440/`. HTML перед отправкой в W3C сохраняется с удалёнными значениями CSRF-токенов. Ответы валидаторов и мобильные отчёты Lighthouse приложены в исходном виде.

Сравнение главной, каталога и входа с макетами: открыть `evidence/comparison/index.html`.
